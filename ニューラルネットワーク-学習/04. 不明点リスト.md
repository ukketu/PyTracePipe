# 不明点リスト

関連: [[00. 学習ガイド]] / [[01. ソース一覧]]

このリストは「読んでわからなかったら次に質問する内容」です。上から順に質問すると理解がつながりやすいです。

## まず質問すると良い

- [ ] ニューラルネットワークを「関数」と見るとは、具体的にどういう意味？
- [ ] 重み $w$ とバイアス $b$ の役割の違いは？
- [ ] 活性化関数がないと、なぜ何層重ねても線形変換になるの？
- [ ] ReLU と sigmoid はどう使い分けるの？
- [ ] 損失関数と評価指標は何が違うの？

## 数式で詰まりやすいところ

- [ ] $z = Wx + b$ の行列サイズを具体例で確認したい。
- [ ] $w \leftarrow w - \eta \frac{\partial L}{\partial w}$ を記号ごとにもう一度説明してほしい。
- [ ] 偏微分 $\frac{\partial L}{\partial w}$ の直感がわからない。
- [ ] chain rule が逆伝播でどう使われるか、簡単な数値例で見たい。

## 実装時に確認

- [ ] PyTorch の `nn.Module` は、このノートのどの概念に対応している？
- [ ] `loss.backward()` は内部で何をしている？
- [ ] `optimizer.step()` はどの式に対応している？
- [ ] ミニバッチとは何で、なぜ全データを一度に使わないの？

## 余裕があれば

- [ ] CNN は普通のニューラルネットワークと何が違う？
- [ ] Transformer もニューラルネットワークなの？ どこが同じでどこが違う？
- [ ] 過学習とは何で、どう防ぐ？
- [ ] なぜ深層学習には大量のデータとGPUが必要になりやすい？
