# ニューラルネットワーク学習ガイド

このフォルダは「ネット上の質の高い教材」から、ニューラルネットワークを初学者向けに学ぶための Obsidian 学習パックです。

## まず見る順番

1. [[01. ソース一覧]] — どの教材を、何のために使うか
2. [[01. ニューラルネットワーク全体像]] — まず大きな絵をつかむ
3. [[02. ニューロンと重み]] — 1つのニューロンの計算
4. [[03. 活性化関数と層]] — なぜ「深く」できるのか

7. [[04. 不明点リスト]] — 次に質問するとよいこと

## この学習パックの方針

- 元ソースを先に示し、その直後に日本語で噛み砕きます。
- 画像・動画サムネイル・Mermaid 図を多めに入れます。
- 不明点は「次に質問する内容」としてチェックリスト化します。
- 数式は必要最低限から始め、記号ごとに意味を説明します。

## 全体マップ

```mermaid
flowchart LR
    A[入力データ x] --> B[重み付き和 z = wx + b]
    B --> C[活性化関数 a = f(z)]
    C --> D[次の層へ]
    D --> E[予測 y_hat]
    E --> F[損失 L]
    F --> G[勾配を計算]
    G --> H[重みを更新]
    H --> B
```

## 最初のゴール

ニューラルネットワークを「魔法の箱」としてではなく、次の3つの繰り返しとして見られるようになること。

1. 入力を重み付きで足す
2. 活性化関数で曲げる
3. 誤差が小さくなるように重みを少しずつ直す
