# 活性化関数と層

関連: [[02. ニューロンと重み]] / [[04. 損失関数・勾配降下法・逆伝播]]

## このノートのゴール

活性化関数がなぜ必要なのか、層を重ねる意味は何かを理解する。

## 交互解説 1: 活性化関数

### 元ソース

CS231n は、ニューロンの出力に非線形な活性化関数を通すことを説明し、sigmoid, tanh, ReLU などを比較しています。  
出典: [CS231n Neural Networks Part 1](https://cs231n.github.io/neural-networks-1/)

### 解説

活性化関数は、ニューロンの計算結果 $z$ を別の値に変換します。

代表例の ReLU は次です。

$$
\mathrm{ReLU}(z) = \max(0, z)
$$

つまり:

- $z > 0$ ならそのまま通す
- $z \le 0$ なら 0 にする

活性化関数がない場合、層を何枚重ねても全体は結局1つの線形変換になります。非線形性が入ることで、曲がった境界や複雑なパターンを表現できます。

### 図で見る

![Sigmoid function](https://upload.wikimedia.org/wikipedia/commons/5/53/Sigmoid-function-2.svg)

```mermaid

    A[線形変換 Wx+b] --> B[活性化関数 ReLU/Sigmoid]
    B --> C[次の層]
```

### 自分で確認する問い

- [ ] 「非線形」とは何が線形でないという意味か？
- [ ] ReLU が $z \le 0$ を 0 にすることで何が起きるか？

## 交互解説 2: 層を重ねる意味

### 元ソース

3Blue1Brown は、画像のピクセルから線や形、さらに数字らしさへと抽象度が上がるイメージで説明します。  
出典: [But what is a neural network?](https://www.3blue1brown.com/lessons/neural-networks)

### 解説

層を重ねると、ネットワークは段階的に特徴を作れます。

```text
ピクセル → 線・端 → 部品 → 全体の形 → クラス
```

ただし、これは人間が明示的に「このニューロンは線を見ろ」と命令するわけではありません。学習の結果として、予測に役立つ中間表現が作られます。

### 図で見る

```mermaid
flowchart LR
    A[生の入力] --> B[低レベル特徴]
    B --> C[中レベル特徴]
    C --> D[高レベル特徴]
    D --> E[予測]
```

## まとめ

活性化関数はネットワークに「曲がる力」を与えます。層を重ねることで、単純な特徴から複雑な特徴へと段階的に変換できます。
