# 図解ギャラリー

関連: [[00. 学習ガイド]] / [[01. ニューラルネットワーク全体像]]

## 1. ネットワーク全体

![Colored neural network](https://upload.wikimedia.org/wikipedia/commons/4/46/Colored_neural_network.svg)

見るポイント:

- 左から右へ情報が流れる
- 丸がニューロン
- 線が重み付き接続
- 層をまたぐごとに表現が変換される

## 2. 人工ニューロン

![Artificial neuron model](https://upload.wikimedia.org/wikipedia/commons/6/60/ArtificialNeuronModel_english.png)

見るポイント:

- 入力 $x_i$ に重み $w_i$ が掛かる
- 足し合わせた値が活性化関数に入る
- 出力が次のニューロンへ渡される

## 3. 活性化関数

![Sigmoid function](https://upload.wikimedia.org/wikipedia/commons/5/53/Sigmoid-function-2.svg)

見るポイント:

- 入力が大きくなると出力が 1 に近づく
- 入力が小さくなると出力が 0 に近づく
- ReLU とは形が違う。sigmoid は滑らか、ReLU は折れ線的

## 5. 1枚で復習する図

```mermaid
flowchart LR
    subgraph Forward[順伝播]
        X[入力 x] --> Z[重み付き和 z=Wx+b]
        Z --> A[活性化 a=f(z)]
        A --> YH[予測 y_hat]
    end
    YH --> L[損失 L]
    Y[正解 y] --> L
    subgraph Backward[逆伝播]
        L -.-> G[勾配 dL/dw]
        G -.-> U[重み更新]
    end
    U --> Z
```
